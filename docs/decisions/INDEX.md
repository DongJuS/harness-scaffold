# decisions

## Purpose

Architecture Decision Records (ADRs) that document why every significant
architectural and implementation choice was made. Each ADR captures the
problem context, alternatives considered, the chosen option, and trade-offs.

## Files

- `./TEMPLATE.md` — ADR template used by scripts/new-decision.sh to create new records
- `./ADR-001.md` — Adopt 200-line file limit and INDEX.md navigation convention

## Dependencies

- `../../scripts/new-decision.sh` — Script that generates new ADR files from the template

## Related

- `../../CLAUDE.md` — AI agent rules that reference ADR conventions
- `../` — Parent docs directory linking all documentation systems
