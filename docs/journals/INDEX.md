# journals

## Purpose

AI work journal entries that record what was done in each session — tasks
performed, files changed, problems encountered, and solutions applied. Each
entry provides an auditable record of AI contributions to the project.

## Files

- `./TEMPLATE.md` — Journal template used by scripts/new-journal.sh to create new entries
- No journal entries yet — use `scripts/new-journal.sh "Objective"` to create the first one

## Dependencies

- `../../scripts/new-journal.sh` — Script that generates new journal entries from the template

## Related

- `../../CLAUDE.md` — AI agent rules that reference journal conventions
- `../decisions/` — Architecture Decision Records (related documentation type)
- `../` — Parent docs directory linking all documentation systems
