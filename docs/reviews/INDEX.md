# reviews

## Purpose

Role-based review records documenting how each completed task was evaluated
from activated role perspectives. Each review pairs conceptual role checklists
with pass/fail/na assessments, issue tracking, and a final verdict.

## Files

- `./TEMPLATE.md` — Review template with per-role checklist, issue tracking, and verdict fields

_No review entries yet._
## Dependencies

- `../../roles/` — Role profiles whose checklists populate each review
- `../../scripts/role-review.sh` — Generates review files and validates for critical issues
- `../../scripts/activate-roles.sh` — Determines which roles to activate per task type

## Related

- `../decisions/` — ADRs that may be referenced as context in reviews
- `../journals/` — Journal entries describing the work being reviewed
