# Policies

## Purpose

Topic-based policy files used by `../CLAUDE.md` to route agents to the right rules.

## Files

- `./core-structure.md` — repository structure rules, 200-line limit, `INDEX.md`, registry, and navigation
- `./automation-workflow.md` — automation scripts and verification workflow
- `./logs-and-decisions.md` — journals, deliberations, ADR authority, rollback, and conflicts
- `./session-collaboration.md` — writing, handoff, session sync, review, and dashboard rules
- `./external-projects.md` — external project registration and cross-project dependency policy

## Dependencies

- `../CLAUDE.md` — entry point that maps task topics to these policy files
- `../START-HERE.md` — context loading guide used alongside these policy files

## Related

- `../docs/` — reference documents named throughout the policy files
- `../scripts/` — automation commands required by the policy files
