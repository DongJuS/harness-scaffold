## Codebase Patterns
- All scripts use `set -euo pipefail` and portable bash (macOS BSD + Linux)
- Scripts resolve `ROOT_DIR` via `SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"` then `ROOT_DIR="$(cd "$SCRIPT_DIR/.." && pwd)"`
- Markdown tables with pipe `|` delimiters break `sed` substitutions — use `awk` or temp files instead
- Placeholder rows like `_(no active sessions)_` are used in empty tables and replaced when first real entry is added
- INDEX.md files follow the format: Purpose, Files, Dependencies, Related sections
- All files must stay under 200 lines — run `scripts/validate.sh` before committing
- Auto-increment IDs by scanning existing files (e.g., ADR-001, JOURNAL-001)
