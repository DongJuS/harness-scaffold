# templates

## Purpose

Reusable templates for project conventions. Used by automation scripts to generate standardized files across the repository.

## Files

- `./INDEX-TEMPLATE.md` — Reference template for INDEX.md files; defines the standard sections every directory index must contain

## Dependencies

- _None_

## Related

- `../scripts/` — Automation scripts that consume these templates (e.g., `create-index.sh`)
